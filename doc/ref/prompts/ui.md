**O que o servidor devolve (a API já existe; Cap. 5 §5.10):** `GET /api/notifications` responde `{ data: [...], unreadCount, nextCursor }` (`?unread=1`, `?limit=` de 1 a 100, padrão 20, `?cursor=`; só as do próprio usuário, também o administrador); cada item traz `id`, `type`, `severity` (`INFO`, `WARNING`, `CRITICAL`), `title` e `text` **em português, como texto puro**, `data`, `readAt`, `resolvedAt`, `createdAt` e `updatedAt`; `PATCH /api/notifications/:id` com `{ read: true }` (idempotente) ou `{ dismissed: true }` responde `{ data, unreadCount }`, e a de outro usuário e a inexistente respondem **404**; `POST /api/notifications/read-all` responde `{ data: { count }, unreadCount }`; **um cursor dispensado entre duas páginas responde 422** (recomece pela primeira página); o limite de taxa das escritas de notificação é de 60 por minuto e o das leituras segue o padrão da API (**não consulte em excesso**).
